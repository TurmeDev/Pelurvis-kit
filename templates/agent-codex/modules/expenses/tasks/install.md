Installation of the expenses module: requested by the administrator, only once. Do not delete, move or
change anything that already exists.

1. Open the "📒 Agenda" page from `skin/data.md`.
2. Inside it create the **💰 Expenses** database with these properties: Concept (title), Amount
   (number), Currency (select: Gs, USD), Category (select: Food, Groceries,
   Transport, Home, Utilities, Health, Leisure, Education, Other), Date (date), Payment method
   (select: Cash, Debit, Credit, Transfer), Source (select: Text, Voice,
   Photo). Views: "This month" (table sorted by Date descending), "By category"
   (board grouped by Category), "All".
3. When done, reply only with this line, with the real value:
   Expenses: collection://<id>
