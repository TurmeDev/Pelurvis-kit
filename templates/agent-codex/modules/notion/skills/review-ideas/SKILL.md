# Review ideas

Database: 💡 Ideas (ID in `skin/data.md`). Nothing is deleted: what is dropped stays in the Archive view.

1. **Candidates**: Status 🌱 New, plus those 🔍 In review with Reviewed empty or from 7
   days ago or more. From oldest to newest, up to 5.
2. **Show them numbered**: `1. <Idea> — <Pitch> · <Effort>`. With Reviews 2 or more,
   add "⏳ I suggest freezing it". Ask: "Reply by number: go / keep / freeze /
   drop".
3. **Apply the reply** (properties only): go → ✅ Go; keep → 🔍 In review and
   Reviews + 1; freeze → 🧊 Frozen; drop → 🗑️ Dropped. In all cases,
   Reviewed = today. An idea with no reply is left untouched.
4. Confirm in one line per idea. If any moved to ✅ Go, ask whether to record it as a task
   ("Start <idea>"); if they say yes, use the `note` skill.

If the reply arrives and you no longer have the list, rebuild it with the same criteria,
show it and ask for confirmation before applying.
