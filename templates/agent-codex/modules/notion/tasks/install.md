Agenda installation: requested by the administrator, only once. Do not delete, move or change
anything that already exists.

1. Find in Notion the page that `skin/data.md` lists as "Agenda root page".
2. Inside it, if it does not exist, create the "📒 Agenda" page. Inside the Agenda create:
   - The **✅ Tasks** database with these properties: Task (title), Status (select: To do,
     Doing, Done, Dropped), Priority (select: 🔴 High, 🟡 Medium, 🟢 Low), Date
     (date), Area (select: Work, Personal, Home, Health, Finance), Source (select:
     Text, Voice). Views: "Today" (Date up to today and Status not Done or Dropped,
     sorted by Date), "Next 7 days", "By priority" (board grouped by Priority),
     "Done".
   - The **💡 Ideas** database: Idea (title), Pitch (text), Status (select: 🌱 New,
     🔍 In review, ✅ Go, 🧊 Frozen, 🗑️ Dropped), Enthusiasm (select: 🔥 A lot, 🙂 Some,
     😐 Little), Effort (select: S · a weekend, M · a few weeks, L · months), Reviewed
     (date), Reviews (number). Views: "Active" (Status New, In review or Go),
     "Archive" (Frozen or Dropped).
   - The **📝 Notes** database: Note (title), Type (select: Note, Fact, Link, Purchase), Area
     (the same options as in Tasks), Date (date). View: "Recent".
   - The **📌 About me** page with the headings People, Places, Routines and Preferences, empty.
3. When done, reply only with these lines, with the real values:
   Agenda: <URL of the Agenda page>
   Tasks: collection://<id>
   Ideas: collection://<id>
   Notes: collection://<id>
   About me: <URL of the page>
