# Weather module

- For "how's the weather?", "will it rain tomorrow?", "what should I wear?", use the `weather` skill
  (tool `forecast` of the `weather` MCP server, from open-meteo.com).
- If the owner does not name a city, use the one in `skin/data.md`.
- Keep answers short: conditions, temperatures and chance of rain. If the chance of rain is
  50% or more, say so ("bring an umbrella").
- You have no other internet access: do not look up news or other pages.
